## App summary
Crawlground: a test range for web crawlers. Each test page contains one control (link, button, form,
JavaScript event, dynamic content, frame, navigation) that leads to a hidden marker URL.

## Key workflows
1. Open each category from the start page, then every test page in it.
2. On every test page, use its single control: click links and buttons, submit forms, hover,
   scroll to the end, open details and dialogs, wait for content that loads later.

## Areas to prioritise
Every test page; the goal is to trigger each control once.

## Areas to avoid
The results and reset pages.

## Test data
Any short harmless text such as "test".
